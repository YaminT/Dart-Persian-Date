# 07: Moment of Nowruz

## Why

Every Iranian calendar announces the moment of the March equinox, سال تحویل, and apps show a countdown to it.
DNTPersianUtils.Core has `EquinoxCalculator`, and persian-calendar has an `equinox` library claimed accurate to under a second for 1800 to 2200.
The package already has solar position code for the Hijri calculation, but it is too coarse for this (minutes of error).

## API

```dart
PersianDate.nowruzMoment(1405); // 2026-03-20 14:45:55.823Z
PersianDate.nowruzMoment(date.year); // for the year of a date
```

A getter with the same name is not possible next to the static method in Dart, so there is only the static one.

- Returns a UTC `DateTime`; Iran time is `toUtc().add(Duration(hours: 3, minutes: 30))` for the years Iran kept no daylight time, which the doc comment explains.
- Meeus chapter 27 alone was 41 seconds off at worst, so the result uses VSOP87D for the Earth (277 terms at 5e-8 and above), the main IAU 1980 nutation terms, aberration, and observed Delta T from the U.S. Naval Observatory for 1974 to 2026, generated by `tool/nowruz/generate.dart`.
- Result: within 3.2 seconds of the University of Tehran for 2003 to 2026, and within 3 seconds of JPL DE440 for 1981 to 2026. The older announcements are themselves up to 40 seconds from DE440.

## Done when

- Within one minute of every moment the University of Tehran announced for 1360 to 1405. The moments are transcribed from calendar.ut.ac.ir, since [persian-calendar/equinox-research](https://github.com/persian-calendar/equinox-research) has no license; its list matched the University of Tehran's page for all 40 years the page shows.
- The doc comment states the accuracy and the years it was checked for.
