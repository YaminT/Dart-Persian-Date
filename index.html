jalali_date

A Persian calendar that behaves like one

Convert between Gregorian and Jalali dates, do arithmetic that clamps to the Persian month, parse Persian and Arabic-Indic digits, and format with Persian month and weekday names. Pure Dart with no dependencies, so it runs on Flutter, the web and the Dart VM.

dart pub add jalali_date

main.dartDart
final nowruz = PersianDate(1400, 1, 1);
nowruz == PersianDate.fromGregorian(2021, 3, 21);  // true
PersianDate(1357, 11, 22).toDateTime();  // 1979-02-11 00:00:00.000

// Persian digits, with a time of day
PersianDate.parse('۱۴۰۳/۰۱/۰۱ ۱۴:۳۰');
// null: 1400 is not a leap year
PersianDate.tryParse('1400/12/30');

// the day is clamped to the target month
PersianDate(1403, 6, 31).addMonths(1);  // 1403/07/30
PersianDate(1403, 12, 30).addYears(1);  // 1404/12/29

What it does

  • Leap years that are right. The conversion is a port of jalaali-js, so century years and leap cycles are handled correctly.
  • Lunar Hijri and Shahanshahi. Hijri dates as Iran’s official calendar counts them, and years written or read in the Shahanshahi numbering.
  • Iranian holidays. The companion iranian_holidays package calculates the official holidays offline or fetches them from an API.
  • Ready for a date picker. Saturday-first weeks, month anchors, day ranges and bounds are built in.
